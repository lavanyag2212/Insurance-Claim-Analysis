# Excel – Insurance Claim Analysis

## Project Overview
This project focuses on analyzing insurance claim data using Microsoft Excel. The main objective is to identify claim patterns, analyze claim amounts, and generate meaningful business insights through an interactive Excel dashboard.

## Dataset
- File Name: Insurance_dataset_proj.xlsx
- Format: Excel (.xlsx)

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers

## Key Performance Indicators (KPIs)
- Total Claims
- Total Claim Amount
- Average Claim Amount
- Approved Claims
- Rejected Claims

## Dashboard Features
- Interactive dashboard
- KPI cards
- Data visualization
- Claim analysis
- Business insights

## Project Objective
To analyze insurance claim data and present useful insights that support better decision-making.
